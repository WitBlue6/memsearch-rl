# 研究计划

目标是区分并测量“记忆保留证据”与“搜索补充证据”各自及共同的作用。

## 范围

第一版为问题已知的任务内记忆，每题结束后清空；不跨题共享记忆，不涉及用户长期画像。检索环境固定，先做 HotpotQA 候选集实验，再扩大语料。保持底层检索器不训练，以便归因。

## 里程碑与验收

1. **环境与协议**：确定性虚构两跳题可跑通；标签不进入 Agent；无效引用、动作超限可检测。已实现。
2. **真实模型基线**：至少 200 道开发题完成 A/B/C/D 提示词基线，随机检查 30 条轨迹。已完成 20 题短程验收，正在建立独立研究划分。
3. **记忆训练**：训练集生成或选择冷启动数据；固定检索序列与 reader，训练 ADD / UPDATE / DELETE / NOOP 记忆操作策略；与同预算摘要和摘录比较。训练入口与短程更新已验证；正式收益仍待多种子实验。
4. **搜索训练**：冻结阶段一记忆，训练 SEARCH / FINISH；先不加成本惩罚，再在开发集调整。训练入口已实现，正式实验未运行。
5. **完整消融**：四组交叉比较，预算 256/512/1024，搜索上限 2/3/4，多个随机种子；所有主结果使用锁定的独立评测集。
6. **扩大验证**：增加干扰文档、不同数据集或更大模型；只有稳定收益才考虑联合训练与 verl 迁移。

## 第一个机制假设

RL 能否学会根据问题和当前记忆，决定新证据值得写入、应该更新已有条目、需要删除哪些旧条目，或者直接忽略？默认策略显式生成 ADD / UPDATE / DELETE / NOOP；合并通过 UPDATE + DELETE 表达。环境只做校验与执行，不自动替策略排序或淘汰。是否有收益必须由正式实验决定。

记忆仍包含来源与可选未解决子问题，但这是表示方式，不等同于决策算法。完整状态 JSON 的 token 计入预算，超限操作整批拒绝并受罚。只有旧摘要对照保留自动裁剪；应额外用同一 GRPO 训练器的 `--memory-mode structured` 比较整体重写策略，区分动作协议与训练本身带来的影响。

当前为每次检索后的一次记忆操作决策；没有统一 SEARCH/WRITE/FINISH 调度器，也没有步骤级奖励或跨任务长期记忆。先固定检索顺序和 reader 验证记忆决策的因果作用，再做搜索策略。

## 固定变量

同一数据版本、候选池、BM25、证据观察上限、模型家族、预算 tokenizer、回答协议；记录所有模型版本与 checkpoint。检索、记忆、决策的开销都计入，不只报告搜索次数。

当前固定检索计划按问题一次排序，逐轮取不相交窗口，完全不依赖记忆内容。学习策略可改写 query，也允许重复检索但照常扣预算。

## 奖励与陷阱

参考训练器使用答案 F1 减去搜索成本及无效输出惩罚。初始 search_cost=0，先保证可学习。暂不把 source ID 命中作为主奖励：复制很多 ID 可以投机，且 ID 命中不保证事实被正确保留。

答案正确也可能来自模型内部知识或猜测；因此必须与无检索／无记忆基线比较，并抽查证据链。没有实现语义蕴含验证时，不报告“引用正确率”或“零幻觉”。

训练与评测 split 必须按原始任务划分；同一问题的不同轨迹不可跨 split。候选语料可以含有公开事实，但标签与 gold support 不进入状态。正式运行前检查问题重复及近重复；官方 dev 中另划调参子集与锁定评测子集。
